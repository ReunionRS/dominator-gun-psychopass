# Косплей-реквизит «Доминатор» из Psycho-Pass

[English version](README.md)

Скетч для Arduino Nano, реконструированный для косплей-реквизита «Доминатор» из Psycho-Pass. Он управляет четырьмя сервоприводами, воспроизводит звуки через DFPlayer Mini и обрабатывает кнопку-спуск. Это реконструкция, а не проверенный оригинальный исходный код проекта.

![Анимация Доминатора](assets/dominator-anime.gif)

![Готовый реквизит](assets/dominator-prop.gif)

## Комплектующие

- Arduino Nano
- 4 совместимых сервопривода
- DFPlayer Mini и карта microSD
- Динамик и усилитель, показанный на приложенной схеме
- Кнопка без фиксации для спуска
- Подходящий источник питания, стабилизатор, провода и резисторы

## Библиотеки Arduino

- `Servo` (входит в Arduino IDE)
- `SoftwareSerial` (входит в Arduino IDE)
- `DFRobotDFPlayerMini` (установите через менеджер библиотек)

## Назначение выводов

| Функция | Вывод Arduino |
| --- | --- |
| Кнопка-спуск | D4 на GND (`INPUT_PULLUP`) |
| Сигналы сервоприводов 1–4 | D7, D5, D6, D8 |
| DFPlayer TX → Arduino RX | A1 |
| Arduino TX → DFPlayer RX | A2 через резистор около 1 кОм |

## Аудиофайлы

Отформатируйте карту microSD в FAT32 и создайте папку `/mp3` с файлами:

| Файл | Назначение |
| --- | --- |
| `0001.mp3` | Запуск |
| `0002.mp3` | Раскрытие/трансформация |
| `0003.mp3` | Парализатор |
| `0004.mp3` | Выстрел Lethal Eliminator |

## Загрузка и калибровка

1. Откройте `dominator_gun_psychopass.ino` в Arduino IDE.
2. Выберите правильную плату Arduino Nano, процессор и порт.
3. Установите `DFRobotDFPlayerMini`, затем скомпилируйте и загрузите скетч.
4. Отсоедините тяги сервоприводов и откалибруйте `CLOSED_ANGLES` и `OPEN_ANGLES` до запуска механизма.
5. Установите `STARTUP_AUDIO_MS` равным реальной длительности `0001.mp3`.

Для стендовой проверки монитор порта на скорости 9600 бод принимает команды `p` (закрыть), `l` (открыть) и `f` (воспроизвести текущий звук выстрела).

## Схема пайки и подключения

![Схема пайки и подключения](assets/wiring-diagram.png)

> **Проверьте до пайки:** на присланной схеме визуально показаны три сервопривода, а скетч настроен на четыре. Сверьте каждое соединение с фактическими компонентами. Не питайте несколько сервоприводов от вывода 5 V платы Nano: используйте стабилизированный источник достаточной мощности и объедините все земли. Используйте защищённые аккумуляторы/подходящую BMS; не допускайте короткого замыкания, перезаряда и глубокого разряда Li-ion элементов.

## Безопасность

Это нефункциональный косплей-реквизит. Соблюдайте местные правила для макетов оружия, используйте оранжевую заглушку или другую обязательную маркировку и не носите реквизит там, где его могут принять за настоящее оружие.

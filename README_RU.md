## О проекте

Реконструированный скетч для косплей-реквизита «Доминатор» из Psycho-Pass на базе Arduino Nano. Три сервопривода управляют механизмом трансформации, а DFPlayer Mini воспроизводит звуки запуска, раскрытия, «Парализатора» и «Смертельного элиминатора».

> Это реконструкция для нефункционального косплей-реквизита, а не проверенный оригинальный исходный код проекта.

## Возможности

- Плавное неблокирующее движение трёх сервоприводов
- Подавление дребезга кнопки-спуска
- Блокировка механизма во время стартового звука
- Четыре звуковых эффекта с карты microSD
- Команды монитора порта для стендовой проверки
- Работа без звука, если DFPlayer не обнаружен

## Комплектующие

| Компонент | Количество | Примечание |
| --- | :---: | --- |
| Arduino Nano | 1 | Основной контроллер |
| Сервопривод | 3 | Усилие подбирается под механизм |
| DFPlayer Mini | 1 | Воспроизведение звука с microSD |
| Динамик и усилитель | 1 | Согласно схеме подключения |
| Кнопка без фиксации | 1 | Спусковой крючок |
| Стабилизированный источник питания | 1 | С учётом пикового тока сервоприводов |
| Резистор | 1 | Около 1 кОм между Arduino TX и DFPlayer RX |

## Подключение

| Функция | Вывод Arduino |
| --- | :---: |
| Кнопка-спуск | D4 → GND |
| Сигнал сервопривода 1 | D7 |
| Сигнал сервопривода 2 | D5 |
| Сигнал сервопривода 3 | D6 |
| DFPlayer TX → Arduino RX | A1 |
| Arduino TX → DFPlayer RX | A2 через ~1 кОм |

> Не питайте сервоприводы от вывода 5 V платы Nano. Используйте стабилизированный источник достаточной мощности и объедините все земли. Используйте защищённые Li-ion аккумуляторы и подходящую BMS; не допускайте короткого замыкания, перезаряда и глубокого разряда.

## Программное обеспечение

- `Servo` — входит в Arduino IDE
- `SoftwareSerial` — входит в Arduino IDE
- `DFRobotDFPlayerMini` — устанавливается через менеджер библиотек

## Аудиофайлы

Отформатируйте карту microSD в FAT32 и поместите файлы в папку `/mp3`:

| Файл | Звук |
| :---: | --- |
| `0001.mp3` | Запуск |
| `0002.mp3` | Раскрытие/трансформация |
| `0003.mp3` | Парализатор |
| `0004.mp3` | Выстрел «Смертельного элиминатора» |

## Загрузка и калибровка

1. Откройте [`dominator_gun_psychopass.ino`](dominator_gun_psychopass.ino) в Arduino IDE.
2. Выберите правильную плату Arduino Nano, процессор и порт.
3. Установите `DFRobotDFPlayerMini`, затем скомпилируйте и загрузите скетч.
4. Отсоедините тяги сервоприводов и откалибруйте `CLOSED_ANGLES` и `OPEN_ANGLES` до запуска механизма.
5. Установите `STARTUP_AUDIO_MS` равным реальной длительности `0001.mp3`.

### Стендовое управление

Откройте монитор порта на скорости **9600 бод**:

| Команда | Действие |
| :---: | --- |
| `p` | Закрыть / режим «Парализатор» |
| `l` | Открыть / режим «Смертельный элиминатор» |
| `f` | Воспроизвести текущий звук выстрела |

## Безопасность

Это нефункциональный косплей-реквизит. Соблюдайте местные правила для макетов оружия, используйте оранжевую заглушку или другую обязательную маркировку и не носите реквизит там, где его могут принять за настоящее оружие.
